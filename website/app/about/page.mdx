# About This Template

Welcome to the **MDX-powered** page of this starter template! 

This page is written directly in standard Markdown and MDX syntax (`app/about/page.mdx`).

---

### What is MDX?

[MDX](https://mdxjs.com/) lets you seamlessly combine **Markdown** writing with interactive **React components**.

- **Markdown formatting**: Lists, bold, italics, links, blockquotes, and code snippets work out of the box.
- **Embedded components**: You can import and render any React component directly inside markdown.
- **Server Components**: Rendered natively on the server with Next.js App Router for optimal performance.

### Example Code Block

```typescript
import createMDX from "@next/mdx";

const withMDX = createMDX();
export default withMDX(nextConfig);
```
