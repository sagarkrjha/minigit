# Installation & Downloads

MiniGit provides pre-compiled standalone executables for Windows, Linux, and macOS, as well as source compilation and container images.

---

## 1. Quick Setup

### Windows
1. Download [`minigit.exe`](https://github.com/sagarkrjha/minigit/releases/latest/download/minigit.exe).
2. Open PowerShell and run the built-in installer to add MiniGit to your PATH:
```powershell
.\minigit.exe install --user
```
3. Restart your terminal and run:
```powershell
minigit --version
```

### Linux / macOS
1. Download the executable:
```bash
# Linux
curl -LO https://github.com/sagarkrjha/minigit/releases/latest/download/minigit-linux
chmod +x minigit-linux

# Or macOS
curl -LO https://github.com/sagarkrjha/minigit/releases/latest/download/minigit-macos
chmod +x minigit-macos
```
2. Install to your local user binary directory:
```bash
./minigit-linux install --user
# or for macOS:
./minigit-macos install --user
```

## 2. Docker Container

If you prefer to run MiniGit via containers:

```bash
# Pull and run directly
docker run --rm -v $(pwd):/data minigit:latest status
```

---

## 3. Verify Download Integrity

Every published release includes SHA-256 cryptographic checksums. Verify your download with:

```bash
# Linux / macOS
sha256sum -c SHA256SUMS.txt

# Windows PowerShell
Get-FileHash .\minigit.exe -Algorithm SHA256
```
