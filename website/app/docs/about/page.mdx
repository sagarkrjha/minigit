# About MiniGit

**MiniGit** is a clean, modern, Git-compatible version control tool and developer platform built under the permissive **MIT License**.

---

## 1. Project Philosophy

MiniGit was created to provide a lightweight, high-performance, and dependable Git-compatible version control engine that removes operational complexity while retaining complete compatibility with modern development workflows.

- **Developer Sovereignty:** Zero telemetries, no third-party account requirements, and no licensing lock-in.
- **Portability:** Standalone native binaries that require no runtime frameworks or dynamic package dependencies.
- **Polyglot Automation:** First-class SDK support across major systems languages (C++, C, Rust, Go) and application languages (Python, TypeScript, Java).

## 3. Technology & Architecture Highlights

- **C++20 Core:** Modern, safe memory management and cross-platform native execution.
- **Standard Git Object Format:** Interoperable SHA hashes, trees, commits, and tags.
- **Cryptographic Security:** SHA-256 integrity verification across all published releases.
