# MiniGit — Open Source Distributed Version Control System

**MiniGit** is a lightweight, fast, Git-compatible distributed version control system and polyglot SDK released under the permissive [MIT License](/docs/license).

Designed as an authentic Git-compatible alternative, MiniGit provides daily developer workflow parity, branch management, remote synchronization, a cross-language SDK, and reproducible Docker distribution.

## Open Source Standards & Governance

MiniGit is committed to open source best practices:

- **Free and Open Source:** Unrestricted use in personal, academic, and commercial environments under the MIT License.
- **Zero Lock-In:** Standard compatibility with Git workflows, remotes, and repository structures.
- **Verifiable Artifacts:** Automated builds with cryptographic SHA-256 checksums published for all release assets.
