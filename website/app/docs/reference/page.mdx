## Quick Command Syntax Table

| Command | Syntax | Primary Purpose |
| :--- | :--- | :--- |
| `init` | `minigit init` | Initialize new repository in working directory |
| `status` | `minigit status` | Display staged, unstaged, and untracked file status |
| `add` | `minigit add <paths...>` | Stage files or directories for the next commit |
| `commit` | `minigit commit -m "<msg>"` | Record permanent snapshot of staged changes |
| `log` | `minigit log` | View backward commit history from current HEAD |
| `diff` | `minigit diff [--cached]` | Compare working directory vs. index vs. HEAD commit |
| `branch` | `minigit branch [<name>]` | List, create, or delete branches |
| `switch` | `minigit switch [-c] <name>` | Switch branches or create and switch simultaneously |
| `merge` | `minigit merge <branch>` | Fast-forward or 3-way merge target branch into HEAD |
| `rebase` | `minigit rebase <upstream>` | Replay branch commits linearly on top of upstream |
| `stash` | `minigit stash [push\|pop\|list]` | Shelve uncommitted modifications temporarily |
| `clone` | `minigit clone <url>` | Clone remote repository into new directory |
| `push` | `minigit push <remote> <ref>` | Publish local commits to remote server |
| `pull` | `minigit pull <remote> <ref>` | Fetch and merge remote commits into current branch |
